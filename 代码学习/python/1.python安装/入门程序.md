在 cmd 中输入 python，直接使用 python

如果想一次性执行多行 Python 代码，可以将多行 Python 代码定义在一个文件中（hello.py），然后在终端里输入 python hello.py 来运行这个文件。

文件命名：Python 脚本文件必须以 .py 为后缀名。
