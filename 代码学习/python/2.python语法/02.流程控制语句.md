# 1.条件判断
## 1.1if 条件判断
场景：只有满足指定条件，才会执行对应的代码逻辑。

```python
# if条件判断基本格式
if 要判断的条件:
    条件成立时，要执行对应的操作
```

注意：Python 中是通过缩进来描述代码的归属的，归属于 if 代码块的语句，需要在前方缩进 4 个空格

## 1.2if...else
```python
# if...else 结构
if 要判断的条件:
    # 条件成立时，执行对应的操作1
    条件成立时，执行对应的操作1
else:
    # 条件不成立时，执行的操作2
    条件不成立时，执行的操作2
```

## 1.3if...elif...else
```python
# if...elif...else结构
if 要判断的条件1:
    # 条件1成立时，执行对应的操作1
    条件成立时，执行对应的操作1
elif 要判断的条件2:
    # 条件2成立时，执行对应的操作2
    条件成立时，执行对应的操作2
else:
    # 前面所有条件都不成立时，执行的操作3
    条件不成立时，执行的操作3
```

# 2.模式匹配
**match...case**

结构模式匹配是用一个清晰的模板去精准匹配数据的结构和内容，匹配成功则执行相应的操作

 基本语法格式：

```python
match 变量:
case 模式1:
    操作1
case 模式2:
    操作2
case _:  # 通配符，匹配所有其他情况
    默认操作
```

# 3.循环
## 3.1while 循环
`while` 循环会在**条件表达式为 **`**True**`** 时**，重复执行缩进的循环体语句，直到条件变为 `False` 才停止。

```python
# while语法结构
while 条件表达式:
    循环体语句1
    循环体语句2
    # ... 更多循环体语句
```

`while...else` 是 `while` 循环的扩展结构，`else` 分支会在 ** 循环正常结束（条件变为 `False`）** 时执行；如果循环被 `break` 中断，则不会执行 `else` 代码。

```python
# while语法结构
while 条件表达式:
    循环体语句1
    循环体语句2
    # ... 更多循环体语句
else:
    # 条件为False，循环正常结束时执行
    条件为False,循环正常结束时执行
```

## 3.2for 循环
`for` 循环本质是**遍历机制**，会逐个取出待处理数据集中的元素并执行循环体；`else` 分支会在循环**正常遍历完所有元素**时执行，若循环被 `break` 中断，则不会执行 `else` 代码。

```python
# for循环结构
for 元素 in 待处理数据集:
    # 对元素进行处理
    循环体代码(对元素进行处理)
else:
    # 循环正常结束时执行
    循环结束时，执行的代码
```

```python
# 定义要遍历的字符串
msg = "Hello-Python"

# 遍历字符串，并处理
for i in msg :
    print(i)
else:
    print("循环结束")
```

### range 语句详解
`range` 用于生成**指定规则的整数序列**，常和 `for` 循环配合使用，核心特点是**左闭右开**（包含起始值，不包含结束值）。

| **用法格式** | **说明** | **示例** | **生成序列** |
| :--- | :--- | :--- | :--- |
| `range(end)` | 从 **0** 开始，到 `end`结束（不含 `end`），步长默认为 1 | `range(5)` | `0, 1, 2, 3, 4` |
| `range(start, end)` | 从 `start`开始，到 `end`<br/> 结束（不含 `end`），步长默认为 1 | `range(2, 8)` | `2, 3, 4, 5, 6, 7` |
| `range(start, end, step)` | 从 `start`开始，到 `end`<br/>结束（不含 `end`），步长为 `step` | `range(0, 10, 2)` | `0, 2, 4, 6, 8` |


## 3.3 循环嵌套
嵌套 `for` 循环是在一个 `for` 循环内部再包含另一个（或多个）`for` 循环，用于处理**多层级数据**。

```python
# for循环结构
for 元素 in 待处理数据集1:
    循环体的代码1
    循环体的代码2
    # ...
    for 元素 in 待处理数据集2:
        循环体的代码1
        循环体的代码2
        # ...
    # ...
# ...
```

### break 语句
只能出现在循环中，表示结束，跳出循环的含义

break 跳出循环时，while 后面的 else 中的代码将不会执行

### continue 语句
只能出现在循环中，表示中断本次循环，直接进入下一次循环
