## 1.2 变量
变量：程序中用来存储数据的容器，把经常变化的数据存入变量

**定义格式：变量名=变量值 num=1114.1**

说明：Python 是动态类型语言，在程序运行时才进行类型检查，变量的类型可以在程序运行时改变（一个变量可以绑定不同的值）。

一条语句可以定义多个变量

## 1.3 标识符
标识符：在代码中为变量，函数，类等起的名字

**变量命名规定**

1. **字符限制**：只能包含字母（a-z, A-Z）、数字（0-9）和下划线（`_`），不能使用其他符号（如 `@`、`#`、空格等）。
2. **开头限制**：不能以数字开头，必须以字母或下划线开头。
3. **关键字限制**：不能使用 Python 内置关键字（如 `True`、`False`、`None`、`if`、`for`、`while` 等）作为变量名。
4. **大小写敏感**：严格区分大小写，例如 `age`、`Age`、`AGE` 是三个完全不同的变量

**变量命名规范**

1. **见名知意**：变量名要能清晰表达变量的用途
2. **下划线连接**：由多个单词组成的变量名，使用下划线 `_` 分隔，这是 Python 官方推荐的 “蛇形命名法”，例如 `user_age`、`product_count`。
3. **全小写字母**：变量名中的英文字母全部使用小写，和类名的大驼峰命名（如 `Student`）做区分

 PEP8: PEP 是 Python 社区的核心技术文档和标准化机制，而 PEP8 是 Python 的代码风格指南 ：[https://peps.python.org/pep-0008](https://peps.python.org/pep-0008)

## 2.1 字符串
### 2.1.1 字符串定义（三种）
```python
# 双引号定义
s1 = "Hello"

# 单引号定义
s2 = 'Python'

s3 = """

    感谢您选择我们公司的产品。
    我们将会为您竭诚的服务。
    祝好 ~

```

**常见的转义字符**

| **转义字符** | **名称** | **作用** |
| :--- | :--- | :--- |
| `\'` | 单引号 | 表示单引号 `'` |
| `\"` | 双引号 | 表示双引号 `"` |
| `\n` | 换行符 | 开始新的一行（换行） |
| `\t` | 制表符 | 增加缩进，缩进一个制表符（tab）的大小 |


### 2.1.2 字符串拼接
很多时候，我们需要将多个字符串拼接起来，可以直接使用（+）进行拼接，方式如下：

```python
# 多个字符串字面量直接写
slogan = "黑马程序员" "成就IT黑马"
print(slogan)

# + 号拼接
slogan = "黑马程序员" + "成就IT黑马"
print(slogan)

s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆: " + s1 + " , " + s2)
```

 注意：+ 号可以用来拼接两个字符串，但是无法将非字符串与字符串进行拼接（若字符串需要拼接数字需先将数字转成字符串）。  

### 2.1.3 字符串格式化
通过 `%`**占位符** 实现字符串与变量的快速拼接，`%` 用于占位，`%s` 表示将变量转换为字符串填入对应位置。

1. **单个变量拼接**

```python
s1 = "涛哥"
print("大家好，我是 %s，欢迎大家进入Python课程的学习" % s1)
```

2. **多个变量拼接**

```python
s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆: %s , %s" % (s1, s2))
```

也可以通过 `f"内容{变量/表达式}"` 的形式来完成快速格式化（推荐）。

```python
# 示例1：单个变量
name = "涛哥"
print(f"大家好，我是 {name}，欢迎大家进入Python课程的学习")

# 示例2：多个变量
s1 = "人生苦短"
s2 = "我用Python"
print(f"吉多·范罗苏姆: {s1} , {s2}")
```

# 3. 输入与输出
input 语句（函数）的功能就是获取键盘输入的数据，具体的用法为：`s = input(提示信息)`

print 语句 (函数) 的功能就是将数据输出到控制台，具体语法为：`print(数据..)`

`print("*", end="")`：`end` 表示的是每一次输出以什么结尾，默认为 \n，`end=""`表示输出以空结束，即不换行

```python
# input(..)
name = input("请输入您的姓名: ")
print(f"欢迎您, {name}")

age = input("请输入您的年龄: ")
print(f"您今年 {age} 岁")
```

# 4.运算符
## 4.1 算术运算符
算术运算符用于执行基本数学运算，作用于一个或多个操作数并产生计算结果。

| **运算符** | **描述** | **举例说明** |
| :--- | :--- | :--- |
| `+` | 加法 | `1 + 5`：1 加上 5 |
| `-` | 减法 | `8 - 3`：8 减 3 |
| `*` | 乘法 | `3 * 8`：3 乘以 8 |
| `/` | 除法 | `10 / 5`：10 除以 5，结果是小数 |
| `//` | 整除 | `10 // 3`：10 整除 3，结果为整数 |
| `%` | 取余 / 求模 | `10 % 3`：10 模于 3，结果为 1（10 除 3 取余数） |
| `**` | 幂指数 | `10 ** 3`：10 的 3 次方 |


优先级：_** 大于 * /  // %_大于 + -

## 4.2 赋值运算符
赋值运算符用于将右侧的值（或表达式结果）保存到左侧变量中。

| **运算符** | **描述** | **实例** |
| :--- | :--- | :--- |
| `=` | 赋值运算符 | 把 `=` 右边的结果赋值给左边变量 |
| `+=` | 加法赋值运算符 | `num += 2`等效于 `num = num + 2` |
| `-=` | 减法赋值运算符 | `num -= 2`等效于 `num = num - 2` |
| `*=` | 乘法赋值运算符 | `num *= 2` 等效于 `num = num * 2` |
| `/=` | 除法赋值运算符 | `num /= 2` 等效于 `num = num / 2` |
| `%=` | 取模赋值运算符 | `num %= 2`等效于 `num = num % 2` |
| `//=` | 取整除赋值运算符 | `num //= 2` 等效于 `num = num // 2` |
| `**=` | 幂赋值运算符 | `num **= 2` 等效于 `num = num ** 2` |


## 4.3 比较运算符
 比较运算符用于判断两个值的关系，运算后返回布尔值（`True` 表示关系成立，`False` 表示关系不成立）。

| **运算符** | **描述** | **实例** |
| :--- | :--- | :--- |
| `==` | 等于 | `a == b` 判断 a 是否等于 b |
| `!=` | 不等于 | `a != b` 判断 a 是否不等于 b |
| `>` | 大于 | `a > b` 判断 a 是否大于 b |
| `>=` | 大于等于 | `a >= b` 判断 a 是否大于等于 b |
| `<` | 小于 | `a < b` 判断 a 是否小于 b |
| `<=` | 小于等于 | `a <= b` 判断 a 是否小于等于 b |


## 4.4 逻辑运算符
逻辑运算符用于连接多个布尔表达式，最终返回一个布尔值（`True` 或 `False`）。

| **运算符** | **描述** | **实例说明** |
| :--- | :--- | :--- |
| `and` | 逻辑与（并且） | 左右两边条件**同时成立**时结果为 `True`，否则为 `False`；即 `True and True = True`，其余情况均为 `False` |
| `or` | 逻辑或（或者） | 左右两边条件**只要有一个成立**结果就为 `True`；即 `False or False = False`，其余情况均为 `True` |
| `not` | 逻辑非（取反） | 对布尔值取反，`True` 变为 `False`，`False` 变为 `True` |
