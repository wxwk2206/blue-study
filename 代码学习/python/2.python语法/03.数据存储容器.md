 一种可以容纳多份数据的数据类型（容器），容纳的每一份数据称之为 1 个元素，每一个元素都可以是任意类型的数据，如：字符串、数字、布尔等。  

| **容器类型** | **是否支持重复元素** | **是否可以修改** | **是否有序** |
| :--- | :--- | :--- | :--- |
| **列表 (list)** | ✅ 支持 | ✅ 可变 | ✅ 有序（按插入顺序） |
| **字符串 (str)** | ✅ 支持 | ❌ 不可变 | ✅ 有序 |
| **元组 (tuple)** | ✅ 支持 | ❌ 不可变 | ✅ 有序 |
| **集合 (set)** | ❌ 不支持（自动去重） | ✅ 可变 | ❌ 无序 |
| **字典 (dict)** | 键不重复，值可重复 | ✅ 可变 | ✅ 有序（Python 3.7+ 保持插入顺序） |


# 1.列表（list）
列表是数据容器中的一类，是一次性可以存储 多个数据（元素） 的容器。

```plain
列表名称 = [元素1, 元素2, 元素3, 元素4, 元素5......]
```

```plain
s = [54, 15, 75, 108, 23, 78, 75]
```
![[Pasted image 20260730162330.png]]


**正向索引**：从前向后访问元素，下标从 **0** 开始。**反向索引**：从后向前访问元素，下标从 **-1** 开始。

**删除：** del s[1] 删除容器的第二个元素

**修改**：s[1] = 1 修改第二个元素为 1

## 1.1 切片
 切片是指对操作的数据**截取其中一部分**的操作。列表、字符串、元组都支持切片操作。  

```plain
序列[起始下标:结束下标:步长]
```

+ **起始下标**：从哪个位置开始截取（包含该位置，默认从 0 开始）
+ **结束下标**：到哪个位置结束截取（**不包含**该位置，默认到末尾）
+ **步长**：每次截取的间隔（默认是 1）

## 1.2 方法
**列表常见方法**

| **方法** | **作用** | **样例** |
| :--- | :--- | :--- |
| `append()` | 在列表**尾部**追加元素 | `s.append(10086)` |
| `insert()` | 在**指定索引之前**插入元素 | `s.insert(0, 92)` |
| `remove()` | 移除列表中**第一个匹配到的值** | `s.remove(75)` |
| `pop()` | 删除指定索引位置的元素（无索引则默认删最后一个） | `s.pop(2)`/ `s.pop()` |
| `sort()` | 对列表排序（元素类型需一致） | `s.sort()` |
| `reverse()` | 反转列表元素顺序 | `s.reverse()` |


# 2.字符串（str）
## 2.1 核心特点
1. **不可变性**：字符串一旦创建，就**无法直接修改**其中的字符（如果要修改，只能生成新字符串）。
2. **有序性**：字符的排列顺序固定，每个字符都有对应的下标（索引）。
3. **可迭代性**：可以用 `for` 循环逐个遍历字符串中的每个字符。

## 2.2 方法
**字符串常用方法**

| **方法** | **作用** | **样例** |
| :--- | :--- | :--- |
| `find()` | 查找子串，返回**第一次出现的索引**，找不到返回 `-1` | `s.find('Python')` |
| `count()` | 统计子串在字符串中出现的**次数** | `s.count('H')` |
| `upper()` | 将字符串中所有字母转为**大写** | `s.upper()` |
| `lower()` | 将字符串中所有字母转为**小写** | `s.lower()` |
| `split()` | 按指定分隔符将字符串**分割成列表** | `s.split(' ')` |
| `strip()` | 去除字符串**两端**的空白或指定字符 | `s.strip()`<br/> / `s.strip('*')` |
| `replace()` | 将指定子串**替换**为新子串 | `s.replace('H', 'C')` |
| `startswith()` | 检查字符串是否以指定子串**开头**，返回布尔值 | `s.startswith('P')` |


# 3.元组（tuple）
## 3.1 介绍
元组是**不可变的序列**，和列表很像，但创建后**不能修改**里面的元素。

**核心特点**

+ 可以存储**不同类型**的元素（比如同时存数字、字符串、布尔值）。
+ 元素**可以重复**、**有序**，支持**索引访问**和**切片操作**。
+ 最关键：**不可修改**（不能增、删、改元素）。

**定义方式**

1. **普通元组**：用小括号 `()` 包裹，元素用逗号分隔

```plain
元组名称 = (元素1, 元素2, ...)
# 示例
t1 = (5, 7, 9, 1, 2, 3, 10, 6, 4, 8, 12, 7, 5)
```

2. **空元组**：两种写法

```plain
元组名称 = ()
元组名称 = tuple()
# 示例
t2 = ()
t3 = tuple()
```

3. **单元素元组**：必须加逗号，否则会被识别为普通变量

```plain
t4 = (1,)  # 正确：元组
t5 = (1)   # 错误：被识别为整数 1
```

## 3.2 方法
| **方法** | **作用** | **示例** |
| :--- | :--- | :--- |
| `count()` | 统计某元素在元组中出现的**次数** | `t = (1, 2, 2, 3); t.count(2)`<br/> → `2` |
| `index()` | 查找某元素在元组中**第一次出现的索引位置** | `t = (5, 7, 9); t.index(7)`<br/> → `1` |


## 3.3 组包与解包
#### 3.3.1. 组包（Packing）
将多个值  合并到一个容器（元组 / 列表） 中：

+ 带括号：`t1 = (5, 7, 9, 1)` → 标准元组组包
+ 不带括号：`t2 = 5, 7, 9, 1` → 自动组包为元组

#### 3.3.2. 基础解包（Unpacking）
将容器解开为独立元素，**分别赋值给多个变量**：

```plain
a, b, c, d = t1  # a=5, b=7, c=9, d=1
```

+ 变量数量必须和容器元素数量**完全一致**。

#### 3.3.3. 扩展解包（`*` 语法）
用 `*变量名` 接收**多个元素**：

```plain
x, *y, z = t2  # x=5, y=[7, 9], z=1
s, *o = t2     # s=5, o=[7, 9, 1]
*o, e = t2     # o=[5, 7, 9], e=1
```

+ `*` 只能出现**一次**，用于收集 “剩下的” 元素，结果是列表。

# 4.集合（set）
## 4.1 介绍
集合（set）是一种**无序、不可重复、可修改**的数据容器：

+ **无序**：元素没有固定顺序，不支持下标索引访问。
+ **不可重复**：自动去重，相同元素只会保留一个。
+ **可修改**：可以添加、删除元素。
1. **普通集合**：用大括号 `{}` 包裹，元素用逗号分隔

```plain
s1 = {"C", "D", "X", "T", "O", "U"}
```

2. **空集合**：必须用 `set()` 定义，不能用 `{}`（`{}` 表示空字典）

```plain
s2 = set()
```

## 4.2 方法
| **操作** | **含义** | **样例** |
| :--- | :--- | :--- |
| `add(..)` | 添加元素到集合中 | `s1.add('t')` |
| `remove(..)` | 移除指定元素（元素不存在会报错） | `s1.remove('t')` |
| `pop()` | 随机删除一个元素并返回 | `e = s1.pop()` |
| `clear()` | 清空集合 | `s1.clear()` |
| `difference()` | 求差集（在 s1 但不在 s2 的元素） | `s1.difference(s2)` |
| `union()` | 求并集（两个集合所有元素） | `s1.union(s2)` |
| `intersection()` | 求交集（同时在两个集合的元素） | `s1.intersection(s2)` |


# 5.字典（dict）
字典在其他语言中也叫哈希表（hash），映射（map）

Python 中的字典（dict）是一种存储 键值对（key: value）的数据容器，核心特点是：以 `key: value` 形式存储数据，**通过键（key）可以快速找到对应的值（value）**。

+ 以 `key: value` 形式存储数据
+ 键（key）**不可重复**，若重复定义后一个会覆盖前一个
+ 字典是**可修改**的容器，支持增、删、改操作

## 5.1 定义方式
1. **普通字典**：用大括号 `{}` 包裹，键值对之间用逗号分隔

```plain
字典名称 = {key: value, key: value, ...}
# 示例
dict1 = {"王林": 675, "李慕婉": 608, "许立国": 478}
```

2. **空字典**：两种写法

```plain
字典名称 = {}
字典名称 = dict()
# 示例
dict2 = {}
dict3 = dict()
```

## 5.2 取值方式
通过 `字典名称[key]` 直接获取对应的值：

```plain
score = dict1["李慕婉"]  # 结果为 608
```

 注意：如果 key 不存在，会直接抛出 `KeyError` 异常。

## 5.3 常用操作

| **类型** | **操作** | **含义** | **样例** |
| :--- | :--- | :--- | :--- |
| **添加** | `字典名称[key] = value` | 往字典中添加 `key-value` 键值对 | `dict1["哥"] = 688` |
| **删除** | `字典名称.pop(key)` | 删除指定 `key`，并返回对应 `value` | `score = dict1.pop("哥")` |
| | `del 字典名称[key]` | 删除指定键值对 | `del dict1["哥"]` |
| **修改** | `字典名称[key] = value` | 修改指定 `key` 对应的 `value` | `dict1["智"] = 658` |
| **查询** | `字典名称[key]` | 根据 `key` 获取 `value`（不存在则报错） | `dict1["哥"]` |
| | `字典名称.get(key)` | 根据 `key` 获取 `value`（不存在返回 `None`） | `dict1.get("哥")` |
| | `字典名称.keys()` | 获取所有 `key` | `dict1.keys()` |
| | `字典名称.values()` | 获取所有 `value` | `dict1.values()` |
| | `字典名称.items()` | 获取所有 `key-value` 键值对 | `dict1.items()` |
