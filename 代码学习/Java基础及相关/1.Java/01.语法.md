### 4.2引用数据类型
#### 4.2.1 类（Class）类型
这是最核心的引用类型，包含两种：

+ **系统预定义类**：Java 内置的类（如`String`、`Date`、`ArrayList`等）；
+ **自定义类**：自己编写的类（如`Person`、`Student`等）。

```java
// 1. 系统预定义类（String是典型的引用类型，且不可变）
String str = "Java"; 
// 2. 自定义类
class Person {
    String name;
    int age;
}
Person p = new Person(); // p是引用，指向Person对象
```

#### 4.2.2 接口（Interface）类型
接口本身不能实例化，但接口的**实现类对象**、接口变量都属于引用类型，包括：

+ 系统内置接口（如`List`、`Map`、`Runnable`等）；
+ 自定义接口。

```java
// 自定义接口
interface Animal {
    void eat();
}
// 实现类
class Cat implements Animal {
    @Override
    public void eat() {
        System.out.println("猫吃鱼");
    }
}
// animal变量是接口类型的引用，指向Cat对象
Animal animal = new Cat();
```

#### 4.2.3 数组（Array）类型
**所有数组（无论存储基本类型还是引用类型）都是引用类型**，哪怕是`int[]`、`char[]`这类存储基本类型的数组。

```java
// 存储基本类型的数组（引用类型）
int[] numArr = new int[]{1, 2, 3};
// 存储引用类型的数组（引用类型）
String[] strArr = new String[]{"a", "b"};
// 二维数组（依然是引用类型）
int[][] twoDArr = new int[2][3];
```

#### 4.2.4 枚举（Enum）类型
Java 中的枚举是`java.lang.Enum`类的子类，本质是特殊的类，属于引用类型。

```java
// 定义枚举
enum Week {
    MONDAY, TUESDAY, WEDNESDAY
}
// week是枚举类型的引用
Week week = Week.MONDAY;
```

#### 4.2.5 注解（Annotation）类型
注解（`@interface`）在 Java 中也是一种特殊的引用类型，常用于代码标记（如`@Override`、`@Deprecated`）。



## 5.标识符（类名，方法名，变量名）
命名规则：由数字，字母，美元符$,下划线_组成，不能以数字开头，不能是关键字，区分大小写
驼峰命名法：
**小驼峰命名法（用于方法、变量）**
1. 单个单词：全部小写
示例：name、age、height
2. 多个单词：首个单词全小写，剩余每个单词首字母大写
示例：appleX、appleY、appleCount
**大驼峰命名法（用于类名）**
1. 单个单词：首字母大写
示例：Snake、Student
2. 多个单词：所有单词首字母全部大写
示例：SnakeGame、HelloWorld

## 7.运算符
### 7.1算数运算符：+-*/%
#### 7.1.1类型转换
隐式类型转换
1. **触发时机**：不同类型的数据进行计算，默认采取隐式转换，Java自动转换，无需手动编写转换代码。
2. **转换步骤1**：运算中如果存在`byte`、`short`类型数据，会先统一提升为`int`类型。
3. **转换步骤2**：取值范围小的数据类型，自动提升为取值范围更大的类型，之后再执行运算。
类型从小到大顺序
byte → short → int → long → float → double
**代码示例1**
```java
byte a = 10;
byte b = 20;
int c = a + b;
```
逻辑：两个byte参与运算，全部转为int，最终结果为int类型。

**代码示例2**
```java
byte a = 10;
double b = 20.3;
double c = a + b;
```
逻辑：byte先转为int，最终提升为double；两数均变为double，运算结果是double。

强制类型转换
1. 触发时机：强制转换不会自动触发，需要手动书写代码
2. 书写格式：目标数据类型 变量名 = (目标数据类型) 被强转的数据;
#### 7.1.2数字运算

### 7.4关系运算符/比较运算符

| 符号 | 说明 | 结果规则 |
| ---- | ---- | ---- |
| == | a==b，判断a是否等于b | 条件成立返回true，不成立返回false |
| != | a!=b，判断a是否不等于b | 条件成立返回true，不成立返回false |
| > | a>b，判断a是否大于b | 条件成立返回true，不成立返回false |
| >= | a>=b，判断a是否大于等于b | 条件成立返回true，不成立返回false |
| < | a<b，判断a是否小于b | 条件成立返回true，不成立返回false |
| <= | a<=b，判断a是否小于等于b | 条件成立返回true，不成立返回false |

### 7.5逻辑运算符

| 符号 | 作用 | 说明 |
| ---- | ---- | ---- |
| & | 与（而且） | 两边条件同时成立才符合要求 |
| \| | 或（或者） | 两边条件只要有一个满足就符合要求 |
| ! | 非（取反） | 将布尔结果反转 |

### 7.6短路逻辑运算符

| 符号   | 作用  | 案例                | 说明                   |
| ---- | --- | ----------------- | -------------------- |
| &&   | 短路与 | a > 1 && a < 10   | 左边结果为false时，右边代码不再执行 |
| \|\| | 短路或 | a < 1 \|\| a > 10 | 左边结果为true时，右边代码不再执行  |

补充区分
1. `&`普通与：无论左边真假，左右两边都会完整执行；`&&`存在短路，开发常用&&。
2. `|`普通或：两边全部执行；`||`存在短路，开发优先使用||。


### 7.7三元运算符

格式：关系表达式? 表达式1: 表达式2;

**计算规则：**
先计算关系表达式的值
- 成立（true）→ 执行表达式1
- 不成立（false）→ 执行表达式2
