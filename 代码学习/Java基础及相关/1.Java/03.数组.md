数组：是一种容器，可以用来存储同种数据类型的多个值

+ 特点1：连续的空间
+ 特点2：数组一旦定义，长度不可改变

## 数组的静态初始化
初始化：指在定义**变量，数组，对象**的时候进行赋值

静态：在定义**变量，数组，对象**的时候，数据是静止的，确定的

静态初始化：创建数组的时候，直接给数组赋值 

**完整格式**
```
数据类型 数组名[] = new 数据类型[]{数据值，数据值...};
int arr [] = new int [] {1,2,3};
```

**简写格式**
```
数据类型 数组名[] = {数据值，数据值...}
int arr [] = {1,2,3}
```


数组的元素访问
索引：索引就是数组的一个编号，也叫做：角标，下标，编号

特点：从零开始，连续加一，不间断

元素访问-->获取
```
变量 = 数组名[索引]
int num = arr[5]
```


元素访问-->修改
```
数组名[索引] = 数据值;
arr[5] = 10;
```


## 数组的遍历
循环来遍历数组，length-->获取数组的长度
```java
int arr [] = {1, 2, 3, 4, 5};
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

## 数组的动态初始化
动态：在定义**变量，数组，对象**的时候，数据是不确定的

初始化：指在定义**变量，数组，对象**的时候进行赋值

初始化默认值：

| 数据类型 | 默认值 |
| ---- | ---- |
| 整型 | 0 |
| 浮点数 | 0.0 |
| 字符 | \u0000 |
| 布尔 | false |
| 引用 | null |

```
数据类型 数组名[] = new 数据类型[长度];
int arr [] = new int [3];
```
