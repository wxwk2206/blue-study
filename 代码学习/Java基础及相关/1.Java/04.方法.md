## 方法
方法：程序中的独立功能，也是**最小的执行单元**，可提高程序的复用性和可维护性

方法的**定义格式**（参数为形参）
```java
public static 返回值类型 方法名 (参数1，参数2...){
    方法体;
    return 返回值;
}
```


方法的**调用格式**（参数为实参）

       方法名（参数1，参数2...）;

注意点：

+ 方法与方法是平级关系，不能进行嵌套
+ 方法不会主动运行，需要去主动调用
+ 方法格式里，（）里面的参数需要一一对应（个数，类型），如果没有才会隐式转换

## 方法重载
1. 同一个类中，定义了多个同名的方法，这些方法具有类似的功能
2. 每个方法具有不同的参数类型和参数个数，这些同名的方法，就构成了重载关系
3. 简单理解：同一个类，方法名相同，参数不同的方法，无需看返回值。

## main方法
```java
public class Memory {
    public static void main(String[] args) {
        …
    }
}
```

1. public：被JVM调用，访问权限最大
2. static：被JVM调用，类名访问
测试类中其他方法也是静态的
3. void：不需要给JVM返回值
4. main：固定的名字，被JVM识别
5. String[] args：用于接收运行的参数，目前不用
