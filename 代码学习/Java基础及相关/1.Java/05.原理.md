**流程：**
HelloWorld.java →【编译】→ HelloWorld.class →【运行】→ JVM（Java Virtual Machine，Java虚拟机）

补充说明：
.class字节码文件不依赖操作系统，Windows、macOS等不同系统只要安装对应JVM，均可运行，实现Java跨平台。

内存地址：内存单元的编号，用来快速的管理内存空间

内存地址的规则
① 32位的操作系统，内存地址以32位的二进制表示
```
地址范围：
0000 0000 0000 0000 0000 0000 0000 0000
～
1111 1111 1111 1111 1111 1111 1111 1111（2^32次方）

共计：42,9496,7296个内存地址（2^32次方）

最大支持内存：42,9496,7296（字节）、4096（MB）
419,4304（KB）、4（GB）
```

② 64位的操作系统，内存地址以64位的二进制表示
```
最大内存地址：2^64
地址范围：0 ~ 2^64

最大支持内存：2^64（字节）
1844,6744,0737,0955,1616（字节）
17,592,186（GB）
17,179（TB）
```
