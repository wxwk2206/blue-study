# 选择
```java
switch（表达式）{
    case 值1:
    语句体1;
    break;
    case 值2:
    语句体2;
    break;
    ...
    default:
    语句体n;
    break;
}
```

I. 表达式：结果支持类型（字符、整数byte/short/int、枚举、字符串）
II. case：用来匹配的值，只能写常量真实数据，不能写变量
III. case：各个case取值不能重复
IV. break：作用为中断、终止，跳出结束整个switch语句
V. default：全部case都匹配不上时，执行default内代码

+ default,case的位置没有顺序，default可以省略
+ case穿透：没有break时，会继续执行下面的语句体
+ switch新特性
```java
int num = 1;
switch(num){
    case 1, 2-> {
        sout("A");
    }
    case 3, 4-> {
        sout("B");
    }
    default -> {
        sout("C");
    }
}
```

```java
int num = 1;
switch(num){
    case 1, 2-> sout("A");
    case 3, 4-> sout("B");
    default -> sout("C");
}
```

下面写法可以继续使用switch语句的输出结果
```java
int a = 10;
int b = 20;
String operator = "+";
int result = switch (operator) {
    case "+" -> {
        yield a + b;
    }
    case "-" -> {
        yield a - b;
    }
    default -> {
        yield 0;
    }
};
System.out.println(result);
```

```java
int a = 10;
int b = 20;
String operator = "+";
int result = switch (operator) {
    case "+" -> a + b;
    case "-" -> a - b;
    case "*" -> a * b;
    case "/" -> a / b;
    default -> 0;
};
System.out.println(result);
```

# 循环
## for循环
```java
for（初始化语句;条件判断语句;条件控制语句）{
  //  for（int i = 1;i <= 100;i++）{
循环体语句
}
```

## while循环
```java
初始化语句
while（条件判断语句）{
    循环体语句
    条件控制语句
}
```

for循环和while循环的区别
1. for循环：循环控制变量定义在for语法结构内部，循环结束后，该变量无法继续访问使用。
2. while循环：循环控制变量定义在while循环外部，不属于while语法结构，循环结束后变量依旧可以正常使用。
```java
for(int i = 1; i <= 5; i++){
    sout("当前数字为:" + i);
}
```

```java
int i = 1;
while (i <= 5) {
    i++;
}
sout("当前数字为:" + i);
```

**for 和 while 的区别**
- for循环：适合明确知道循环次数或者循环取值范围的场景
- while循环：不清楚循环次数与范围，仅确定循环终止条件时使用

## 循环嵌套
```java
for (int i = 1; i <= 4; i++) {
    // 在一行打印5个*
    for (int j = 1; j <= 5; j++) {
        System.out.print("*");
    }
    // 换行
    System.out.println();
}
```

## 循环控制语句break/continue
### break
不能单独书写，只能写在switch或循环中，表示结束，跳出的意思

```java
for (int i = 1; i <= 100; i++){
    if (i == 15){
        break;
    }
}
```

### continue
不能单独写，只能写在循环当中，结束本次循环，继续下次循环
```java
for (int i = 1; i <= 10; i++) {
    if(i == 3){
        continue;
    }
    System.out.println(i);
}
```
