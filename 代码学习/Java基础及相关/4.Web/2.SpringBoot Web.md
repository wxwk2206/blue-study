## Spring Boot
Takes an opinionated view of building Spring applications and gets you up and running as quickly as possible.
翻译：以约定优先的思路构建Spring应用，让程序可以极速搭建并运行。

## Spring Framework
Provides core support for dependency injection, transaction management, web apps, data access, messaging, and more.
翻译：提供依赖注入、事务管理、Web应用、数据访问、消息通信等全套核心基础能力。

## Spring Data
Provides a consistent approach to data access – relational, non-relational, map-reduce, and beyond.
翻译：为关系型数据库、非关系型数据库、MapReduce等各类数据场景提供统一的数据访问方案。

## Spring Cloud
Provides a set of tools for common patterns in distributed systems. Useful for building and deploying microservices.
翻译：提供分布式系统常用开发工具，适用于微服务搭建与部署。

## Spring Security
Protects your application with comprehensive and extensible authentication and authorization support.
翻译：提供全面、可扩展的认证与授权能力，保障应用安全。

## SpringBoot入门程序

①创建springboot工程，并勾选web开发相关依赖。
![Pasted image 20260703172143](../../../PNG/Pasted%20image%2020260703172143.png)

②定义HelloController类，添加方法hello，并添加注解。
```java
@RestController //标识当前类是一个请求处理类
public class HelloController {

    @RequestMapping("/hello") //标识请求路径
    public String hello(String name){
        System.out.println("HelloController ... hello : " + name);
        return "Hello " + name + " ~ ";
    }

}
```
