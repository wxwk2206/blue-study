MyBatis是一款优秀的**持久层**框架，用于**简化JDBC**的开发
完整调用流向:
前端请求 → 控制层 controller → 业务层 service → 持久层 dao（MyBatis 实现）→ 数据库
## JDBC
```java
public void testSelect() throws Exception {
    //1. 准备工作
    //1.1 注册驱动
    Class.forName("com.mysql.cj.jdbc.Driver");

    //1.2 获取连接对象Connection
    Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/web","root","1234");

    //1.3 获取SQL语句执行对象PreparedStatement
    PreparedStatement ps = connection.prepareStatement("select * from user");

    //2. 执行SQL语句，处理结果
    List<User> userList = new ArrayList<>();
    ResultSet resultSet = ps.executeQuery();
    while (resultSet.next()){
        int id = resultSet.getInt("id");
        String username = resultSet.getString("username");
        String password = resultSet.getString("password");
        String name = resultSet.getString("name");
        int age = resultSet.getInt("age");

        User user = new User(id,username,password,name,age);
        userList.add(user);
    }

    //3. 释放资源
    resultSet.close();
    ps.close();
    connection.close();
}
```

## Mybatis
```java
@Mapper
public interface UserMapper {
    /**
     * 查询全部
     */
    @Select("select * from user")
    public List<User> findAll();
}
```
