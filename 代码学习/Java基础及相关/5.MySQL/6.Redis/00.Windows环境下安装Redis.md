安装完后的安装目录中有几个常用的文件：

redis.windows.conf文件--当我我们安装成功以后如果启动redis的时候有错误，那么我们需要打开这个文件修改maxheap配置属性的数据值和maxmemory配置属性的数据值。

redis-server.exe文件--启动redis服务【默认安装成功以后自动启动】

redis-cli.exe文件--redis客户端窗口启动。
