## UDP介绍
```
通过Java程序来创建一个基于UDP协议的网络通讯程序

1.什么是UDP，它的优缺点是什么？
UDP--->用户数据报协议[无连接的协议]
优点:消耗小，效率高
缺点:不能保证数据的安全与可靠。

打包---》发送---》接收---》拆包


2.UDP的网络通讯程序需要使用的类和常用方法
基于UDP的网络通讯程序是不区分客户端操作类和服务器端操作类
java.net.DatagramPacket---该类表示数据报包。

1.打包数据-----DatagramPacket的构造方法
DatagramPacket(byte[] buf, int length, InetAddress address, int port) ----打包数据为了发送
byte[] buf----被发送数据
int length----被发送数据大小
InetAddress address----目标计算机的ip地址
int port------目标计算机的端口
例如:有一个字符串数据"hello",发送到本机的3000端口
String  msg = "hello";
byte msgbyte[]=msg.getByte();
int  len = msgbyte.length；
InetAddress   benjiip=InetAddress.getHostAddress();
int  port = 3000；
DatagramPacket  sendPacket = new DatagramPacket(msgbyte,len,benjiip,port)

DatagramPacket(byte[] buf, int length)------打包数据为了接收
例如:创建一个空包，准备接收数据
byte  infobyte[]=new byte[100];
int length = 100;
DatagramPacket  repacket = new DatagramPacket(infobyte,length);

2.拆包数据----DatagramPacket的实例方法
byte[] getData()-----得到DatagramPacket的数据包中的数据值
int   getLength()-----得到DatagramPacket的数据包大小
InetAddress  getAddress() ----得到发送者的ip地址
int   getPort()--------得到数据发出的端口

java.net.DatagramSocket---用于发送和接收数据报数据包的对象
构造方法
DatagramSocket(int port) -----接收发送来的数据包
DatagramSocket() -------------发送数据包
实例方法
void  send(DatagramPacket p)  ----执行发送数据包操作
void  receive(DatagramPacket p)---执行接收数据包操作
void  close() 关闭DatagramSocket。   
```

## 示例：
要求:计算机A从控制台得到一个"hello"数据，发送给计算机B,计算机B显示出计算机A发送的"hello"数据
### 计算机A
```java
package com.qiming.udpdemo;

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.InetAddress;

/**
 *  读取控制台数据发送被计算机B
 */
public class JiSuanJi_A {
    public static void main(String[] args) {
        //定义一个读取控制台数据的输入流
        BufferedReader  conRead = null;
        //定义保存控制台数据的变量
        String  conString = null;
        //定义一个打包发送数据包的变量
        DatagramPacket sendPacket = null;
        //定义发送数据的DatagramSocket
        DatagramSocket  sendSocket = null;
        try {
            //创建BufferedReader对象
            conRead = new BufferedReader(new InputStreamReader(System.in));
            System.out.println("请输入需要发送的数据:");
            conString = conRead.readLine();
            //打包需要发送的数据包
            //DatagramPacket(byte[] buf, int length, InetAddress address, int port)
            //byte msgbyte[]=conString.getBytes();
            //int len = msgbyte.length;
            //InetAddress inetAddress = InetAddress.getLocalHost();
            //int port = 3000;
            sendPacket = new DatagramPacket(conString.getBytes(),conString.getBytes().length,InetAddress.getLocalHost(),3000);
            //创建发送的数据的DatagramSocket
            sendSocket = new DatagramSocket();
            //发送数据包
            sendSocket.send(sendPacket);
            //关闭DatagramSocket
            sendSocket.close();
        }catch(Exception e){
            e.printStackTrace();
        }
    }
}

```

### 计算机B
```java
package com.qiming.udpdemo;

import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.InetAddress;

/**
 * 接收发送来的数据包，拆包，显示
 */
public class JiSuanJi_B {
    public static void main(String[] args) {
        //定义接收数据的DatagramSocket
        DatagramSocket  receiveSocket = null;
        //定义接收数据的空包DatagramPacket
        DatagramPacket receivepacket = null;

        try {
            //创建接收数据的DatagramSocket
            receiveSocket = new DatagramSocket(3000);
            //创建接收数据的空包
            byte infobyte[] = new byte[100];
            receivepacket = new DatagramPacket(infobyte, infobyte.length);
            //接收数据包
            receiveSocket.receive(receivepacket);
            //拆包
            //byte[] getData()-----得到DatagramPacket的数据包中的数据值
            byte  recbyte[]=receivepacket.getData();
            //int   getLength()-----得到DatagramPacket的数据包大小
            int len = receivepacket.getLength();
            //InetAddress getAddress() ----得到发送者的ip地址
            InetAddress  senderInetAddress = receivepacket.getAddress();
            //int   getPort()--------得到数据发出的端口
           int  fachuport = receivepacket.getPort();
           //将拆出的数据转换成字符串
           String showString = new String(recbyte,0,len);
           System.out.println("来自"+senderInetAddress.getHostAddress()+":"+fachuport+"的消息："+showString);
            receiveSocket.close();
        }catch(Exception e){
            e.printStackTrace();
        }
    }
}
```
